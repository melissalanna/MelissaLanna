### 💸 PlanejaPlus — Controle financeiro para MEIs

Aplicação web desenvolvida em equipe para ajudar microempreendedores individuais a organizar suas finanças.

- 📈 Registro de receitas e despesas com visualização em gráficos.
- 🗄️ Modelagem e implementação do banco de dados MySQL.
- 🔐 Desenvolvimento da página de login.
- 🧪 Testes de funcionalidades e configuração de variáveis de ambiente.

**Tecnologias:** HTML · CSS · JavaScript · MySQL · Chart.js
